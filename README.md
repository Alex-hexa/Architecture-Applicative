# LeMauvaisCoin
La version "Lite" du Bon Coin avec une architecture N-tier.

## Filtre :
### Article :
- Date de parution
- Prix
- Titre
### Commande :
- Date
- Utilisateur

## Trie :
### Article :
- Date de publication
- Prix (croissant/décroissant)
### Commande :
- Date

## Pertinence :
### Article :
- Catégorie
